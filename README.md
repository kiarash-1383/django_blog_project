# Django Blog Project with T-SQL

A robust, multi-page blogging platform built with **Django** and powered by **Microsoft SQL Server (T-SQL)**. This project demonstrates CRUD operations, form handling, and relational database management.

## 🚀 Features
- **Multi-page Architecture:** Includes Home, Blog Posts, and Detail views.
- **T-SQL Integration:** Connected to a Microsoft SQL Server database for reliable data storage.
- **Django Forms:** Custom-built forms for post creation and user interactions.
- **Class-based Views:** Efficiently handled logic using Django's views.
- **Secure Authentication:** Integrated Django's built-in security for data management.

## 🛠️ Tech Stack
- **Backend:** Python, Django
- **Database:** Microsoft SQL Server (T-SQL)
- **Frontend:** HTML5, CSS3, JavaScript
- **ORM:** Django ORM for complex SQL queries
